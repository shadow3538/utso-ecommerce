# UTSHO E-Commerce

## Stack

Node.js, Express.js, MongoDB, Mongoose, Socket.IO, Bootstrap, jQuery.

## Admin

The admin username and password come from `.env`.

Admin features include dashboard statistics, product CRUD, product search, pagination, product archive, order search, order filtering, order status management and realtime updates.

## Store

The store includes product search, category filtering, sorting, pagination, product details, local cart, guest checkout, stock validation, order tracking and realtime product refresh.
